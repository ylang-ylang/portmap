Add connection

Enter a node name such as voxmani to fill its domain and proxy host. Addresses you edit manually stay unchanged. A short host requires working name resolution, such as Tailscale MagicDNS; otherwise enter its actual IP or hostname.

The actual port and credentials are still required; they cannot be inferred from a name. For a display-only name, fill the addresses yourself.

Matches this exact domain and its descendants, such as app.node.portmap. Overlapping connections are not allowed, including disabled ones.

Use a reachable authenticated SOCKS5 node address, not a URL or .portmap hostname. Credentials must each contain 1 to 255 UTF-8 bytes. DNS for Portmap addresses is handled at the node. The extension never starts a workspace. SOCKS5 sends credentials and HTTP content without extra encryption: use it only over Tailscale or another trusted encrypted private network.

Local configuration, explicit routing

Connections and passwords stay in this Firefox profile's local extension storage, not Firefox Sync. They are not encrypted by this extension. Requests, content and proxy credentials for enabled .portmap domains are transmitted to the node you choose; the node can observe HTTP traffic. No analytics or central connection manager is used.

Unconfigured or disabled .portmap addresses are blocked, including while connections load or change. Other websites retain Firefox's normal network behavior. Allow this extension in private windows if you need routing and blocking there; it cannot protect windows where Firefox disables it. Disabling or uninstalling the extension removes its protection. Existing open streams may continue until closed.

Open node uses HTTP by default. HTTPS requires a trusted certificate for the original .portmap name and a node configured with a namespace-isolated TLS ingress. No TLS verification is bypassed.
